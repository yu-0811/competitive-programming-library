# 比較関数を直接渡せる安定ソート

`algorithm_library/python/techniques/CmpSort.py` の `cmp_sort(a, cmp)` は、
リスト `a` を並べ替え、その同じリストを返す。比較関数は
`cmp(x, y) < 0` なら x が先、`== 0` なら同順位、`> 0` なら y が先とする。
負・正の値は -1・1 に限らない。一貫した順序を定める任意の比較関数を渡せる。

```python
from algorithm_library.python.math.AngularSort import compare
from algorithm_library.python.techniques.CmpSort import cmp_sort

points = [(0, 1), (1, 1), (1, 0), (0, -1)]
points = cmp_sort(points, compare)
# [(1, 0), (1, 1), (0, 1), (0, -1)]

# 入力を変更したくない場合
ordered = cmp_sort(points[:], compare)
```

偏角比較の `compare` に原点 `(0, 0)` を渡す場合は、事前に原点を分離する。
既存の Library Checker 用コードも原点を別扱いにしている。

再帰を使わないマージソートで、比較関数を直接呼び出す。
最初に全体が単調かを調べ、昇順ならそのまま、狭義降順なら反転して返す。
それ以外では幅1の区間から始め、隣り合う区間を幅を2倍にしながらマージする。
同順位の要素の元の順序を保つ。
時間計算量は最悪 O(n log n)、追加領域は O(n)。
整列済み・全要素同順位・狭義逆順は O(n) で処理する。
比較関数1回の実行時間は O(1) としている。

## 測定条件

- 測定日: 2026-10-25
- CPU: AMD Ryzen AI 7 350 / Linux x86_64
- PyPy 7.3.20 / Python 3.11.13
- 比較対象: `a.sort(key=cmp_to_key(compare))`
- 両方とも同じ `AngularSort.py` の `compare` を使用。
- ランダム入力は各座標を [-10^9, 10^9] から生成し、原点を除外。
- 入力生成・コピー・明示的な GC・出力・結果検証は計測区間に含めない。
  ソート中のメモリ確保・自動 GC・JIT コンパイルは含む。
- 初回は毎回新しいプロセスで最初のソートを測り、3回の中央値を採用。
  プロセス起動・入力読込は含めない。
- 反復実行はサイズ・入力分布ごとにプロセスを分離し、両手法を2回ずつ実行後、
  実行順を交互に変えて5回測定した中央値。別の入力分布の JIT 履歴を持ち越さない。
- 全実行で `cmp_to_key` 版とリスト全体が一致することを検証。
  同順位の点の順序も一致させる。

倍率は `cmp_to_key` の時間 / `cmp_sort` の時間。1未満は `cmp_sort` が遅い。
同じ環境でも JIT の履歴や負荷で結果は変動する。

## 再現方法

リポジトリ直下で実行する。標準ライブラリ以外の依存は不要。
`--sizes`・`--cases`・`--repeat`・`--warmup`・`--seed` で条件を変更できる。

```bash
# 反復実行。各入力分布・サイズを別プロセスで測定
pypy3 -B tests/math/benchmark_cmp_sort.py --sizes 200000

# 初回: 20万点の全入力分布
pypy3 -B tests/math/benchmark_cmp_sort.py --sizes 200000 --fresh-process --repeat 3

# 初回: 小さい入力を含むランダム入力
pypy3 -B tests/math/benchmark_cmp_sort.py --sizes 1000 10000 100000 --cases random --fresh-process --repeat 3

# CPython
python3 -B tests/math/benchmark_cmp_sort.py --sizes 100000 --cases random

# 正しさと生成ファイルの検証
python3 -B -m unittest discover -s tests/math -p 'test_cmp_sort.py' -v
pypy3 -B -m unittest discover -s tests/math -p 'test_cmp_sort.py' -v
python3 library-checker-submitcode/generate.py --check
```

単体テストでは短い整数列の全列挙、run 境界、昇順・降順・重複、
辞書要素の安定性、偏角比較、多倍長整数、戻り値が入力リスト自身であることを検証する。

さらに、ローカルにある Library Checker 問題集のリビジョン
`1814c4e5205517e368bb57a8d1127eb961cfeaae` の
`geo/sort_points_by_argument/info.toml` に従って全21ケースを生成した。
更新した提出コードを PyPy で実行し、公式 C++ 解法を基準に公式 checker で判定して
全ケース通過を確認した。起動・入出力を含む最長時間は 0.617 秒だった。
